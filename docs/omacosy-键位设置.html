omacosy 当前键位设置

更新：2026-10-17 · 窗口管理器：AeroSpace · Super = Option（⌥）

Super 就是 Option（⌥）。Command（⌘）仍是 macOS 原键：复制粘贴、关标签、退出 App、⌘Tab 切 App。
Caps Lock 没有改，方便中文输入法。系统菜单栏平时隐藏；只有系统原生全屏时，鼠标移到顶端才会滑出菜单栏和三个圆钮。

打开 App 与系统

键位作用
⌥ Enter打开终端 Ghostty
⌥ Shift Enter打开 Chrome
⌥ Shift F在访达里打开家目录
⌥ Shift M打开网易云音乐
⌥ Shift G打开 ChatGPT
⌥ Space搜索本机文件和 App（⌘Space 仍是系统搜索）
⌥ K打开 / 关闭这张键位表（Esc 也能关，直接打字可筛选）
⌃ ⌥ L立刻锁屏

窗口

键位作用
⌥ ←↓↑→按方向切换焦点窗口
⌥ Shift ←↓↑→和那个方向的窗口互换位置
⌥ ` / ⌥ Shift `在本工作区的窗口间正向 / 反向轮换（含浮动窗）
⌥ S把下一个浮动窗口调到最前，鼠标跟过去
⌥ W 或 ⌥ Q关闭当前窗口（⌘W 是关标签）
⌘ H隐藏当前 App，留在当前工作区不跳走；点下栏图标或 ⌘Tab 把它取回到当前工作区

布局与大小

键位作用
⌥ T当前窗口在平铺 / 浮动之间切换
⌥ J切换分割方向（左右 / 上下）
⌥ - / ⌥ =缩小 / 放大当前窗口
⌥ F铺满全屏并盖住顶栏，仍在当前工作区；再按退出。鼠标移到顶端顶栏会浮出
⌥ N系统原生全屏（独立桌面，等同绿钮）
⌥ R进入调整大小模式（见下）
⌥ Shift ;进入服务模式（见下）

窗口自动平铺：两个左右分，更多递减分割。绿钮的悬停分屏是系统功能，和 omacosy 的可用区域对不齐，不要用它排窗口。Esc 不能退出全屏。

调整大小模式（⌥R 之后）

键位作用
H / L宽度 −50 / +50
J / K高度 +50 / −50
- / =整体缩小 / 放大
Enter 或 Esc退出调整大小模式

服务模式（⌥ Shift ; 之后）

键位作用
Esc重载 AeroSpace 配置并退出服务模式
R重置当前工作区的布局
Delete ⌫关掉本工作区除当前窗口外的所有窗口

工作区与显示器

键位作用
⌥ 1 … ⌥ 9切到当前显示器的工作区 1–9
⌥ Shift 1 … ⌥ Shift 9把当前窗口移到工作区 N 并跟过去
⌥ Tab / ⌥ Shift Tab当前显示器的下一个 / 上一个工作区
⌃ ⌥ Tab在最近两个工作区之间来回
⌃ ⌥ Shift Tab焦点切到下一台显示器
⌥ Shift O把当前窗口送到另一台显示器的同号工作区
⌥ Shift Space把整个工作区送到另一台显示器

主屏工作区 1–9，外接屏 11–19，末位数字相同的是同一槽。拔掉外接屏时，它上面的窗口会并入主屏的空槽。

触控板（四指）与工作区总览

操作作用
四指左右滑切换指针所在显示器的工作区（含空工作区，到头循环）
四指上滑 / 下滑打开 / 关闭工作区总览
总览里：点卡片、底部数字或按 1–9切到那个工作区
总览里：拖动卡片重排工作区
总览里：直接打字 / Enter按窗口标题搜索 / 进入第一个结果
总览里：Esc先清空搜索，再按关闭总览

系统的三指、四指切桌面和 ⌃←/⌃→、⌃↑ 已关掉，避免切出 macOS 自己的桌面。处于系统原生全屏时切工作区会先退出全屏，切回来会重新进入全屏。

顶栏

操作作用
苹果图标关于本机、系统设置、锁屏、屏保、睡眠、重启、关机、主题列表
工作区数字切换工作区。只有一个窗口时显示它的 App 图标
天气 / Wi-Fi / 蓝牙点击弹出详情
亮度：滚轮 / 点击调亮度，滚过 0 继续压暗；弹出里有夜览开关
音量：滚轮 / 点击调音量；弹出里有滑杆和输出设备
电池打开系统电池设置
铃铛通知排序和预览方式，以及通知、专注模式设置入口
时钟弹出月历
最右边活动图标在 Ghostty 里打开 btop

下栏（Dock）

操作作用
鼠标移到屏幕底边弹出下栏
点 App 图标没开就打开；已开就跳到它的窗口，再点在它的多个窗口间轮换
点已隐藏的 App把它取回到当前工作区（当前是系统原生全屏时，放到一个空工作区）
右键图标打开、选项（在下栏中保留、登录时打开、在访达中显示）、隐藏、退出；按住 ⌥ 变成强制退出

主题与屏保

键位作用
⌥ Shift T切到下一套主题（苹果菜单 → Theme 可直接选）
⌥ Shift B切到当前主题的下一张壁纸
苹果菜单 → Screensaver立刻开屏保；闲置时也会自动开。按键或点击退出并锁屏

现有主题：azure、enter-the-matrix、no-bad-memories、snow-black、space-monkey。每套主题记住上次的颜色和壁纸。

macOS 原生键（菜单栏隐藏后照常可用）

键位作用
⌘ Tab / ⌘ `切换 App / 同一 App 的窗口间切换
⌘ Space系统搜索，也能用来找记不清的菜单项
⌘ N / ⌘ T新窗口 / 新标签
⌘ O / ⌘ S / ⌘ Shift S打开 / 保存 / 另存为
⌘ W / ⌘ Q关标签 / 退出 App
⌘ X ⌘ C ⌘ V ⌘ A剪切 / 复制 / 粘贴 / 全选
⌘ Z / ⌘ Shift Z撤销 / 重做
⌘ F查找
⌘ ⌥ H隐藏其它 App
⌘ ,当前 App 的设置
⌘ Shift 3 / 4 / 5截图 / 录屏
⌃ ⌘ F系统原生全屏（同 ⌥N）

终端日常

键位作用
cd进入目录。单独用回到主目录，cd - 回到上一个
ls -la列出文件，含隐藏文件
pwd打印当前目录
mkdir -p新建文件夹，中间缺的目录一起建
cp -R复制。文件夹要加 -R
mv移动或改名
rm -r删除。没有废纸篓
open .用访达打开当前目录

Neovim

键位作用
i / Esc开始写字 / 回到普通模式
h j k l左、下、上、右
:w / :q保存 / 退出。:wq 保存并退出，:q! 不保存退出
u / Ctrl R撤销 / 重做
dd / yy / p剪切一行、复制一行、贴到下一行
o / O在下面或上面新开一行并开始写
dw / cw删掉一个词，或删掉后接着改
gg / G到文件开头、结尾
/文字向下搜索。n 下一个，N 上一个
:e 文件打开另一个文件，Tab 补全名字
"+y / "+p复制到系统剪贴板，或从剪贴板贴进来
